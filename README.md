# Physics Torches

Minecraft mod that lets you throw your torches like an actual object.

## Usage

Hold a torch and press **R** to throw it. Rebind the key in **Options → Controls** under **Physics Torches**.

## Install

Download it from [Modrinth](https://modrinth.com/project/physics-torches) or [GitHub Releases](https://github.com/skippi/physics-torches/releases).
